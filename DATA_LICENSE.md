## Retail data

The tables in `data/` (and `Sales.csv` in the Release) are derived from:

Chen, D. (2012). *Online Retail II* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D

The source is licensed under Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/. The derived tables are shared under the same licence. They were cleaned and restructured; `data/README.md` lists the changes. The original creator does not endorse this project.

## Map boundaries

The report's shape map loads country boundaries at view time from the `world-atlas` npm package (version 2, served by jsDelivr). That package is derived from Natural Earth data. No boundary file is redistributed in this repository.
